# Phase 5 — Teaching intelligence contract

- A teacher-only Intelligence classroom tab summarizes current approved rubric questions using fixed-precision question marks. Missing, unapproved, withdrawn, unreadable, blank, and rubric-mismatched work are distinct; missing work is never zero. Summaries describe the reviewed cohort, not an inferred diagnosis.
- Findings are suggestions grounded in immutable, reviewed answer/decision/rubric snapshots. A teacher selects a question and topic, optionally an explicit student subset. Every finding cites exact nonempty answer substrings and source pages; IDs, quotes, pages, duplicate citations, and claimed evidence counts are validated. No confidence or cheating/ability labels. Insufficient evidence produces an empty finding set with limitations. Source data is untrusted content, never model instructions.
- Local Ollama is the sole AI provider. Structured responses are validated server-side. Model digest, prompt version, input digest, usage, sources, attempts, and state are retained. Context limits fail explicitly rather than silently truncating or sampling a class. A manual evidence-backed finding path remains available.
- Analysis and generation use durable PostgreSQL jobs, restricted worker claims/leases, bounded explicit retry/cancel, and before/after source revalidation. Revoked access, changed reviewed work or rubric, and changed finding approval invalidate pending outputs. No job approves marks or sends messages.
- Teachers accept or dismiss individual findings with append-only review history. Topic summaries link to inspectable evidence. Accepted findings can ground either a remedial assignment or revision pack. Generation receives teaching concepts and accepted explanations, not student identities, quotes, or marks.
- Material has a reviewable student section and a separate teacher answer key. Teachers edit versioned titles, introductions, learning objectives, revision notes, questions, hints, answers, and rationale. Manual authoring is supported. No HTML from model output is executed.
- Explicit teacher approval of a current material version creates exactly one unpublished Phase 4 assignment version. Answers, teacher rationale, student names, source excerpts, and individual scores are not inserted by the conversion. Publishing still requires the Phase 4 audience review. Existing assignments and marks are untouched. Student/teacher Markdown exports are separate and authenticated; the student export excludes answer keys and source records.
- All new records carry workspace/class scope, scoped foreign keys, RLS, and audits. Students and unrelated teachers cannot read source snapshots, findings, teacher materials, runs, or answer keys. Reviewers may inspect, but only editors may generate, review, edit, or approve.

Completion: inspect summaries and citations → accept findings → generate/edit remedial or revision content → explicitly approve → inspect an unpublished assignment → publish separately. Verify source drift, exact evidence checks, worker recovery, permissions, answer-key separation, idempotent approval, real local Ollama, and browser flow. This establishes workflow correctness, not educational or model accuracy.
